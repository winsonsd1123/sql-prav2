# admin 深侧栏：若依式侧栏 token 族 + 边框阶单调改名（#93）

日期：2026-11-03 · 票：#93（父 spec #90，ADR 0011）· 分支：feature/ruoyi-ui-93（基点 32106ca = main，#92 merge）· 施工方：Cursor

## 上下文

#92 已把若依浅色色板收成中文 token 单一事实源。本票只做两件事：admin 导航换深色侧栏皮肤（布局、窄屏横滑、`aria-current` 不动），以及把边框阶从深度倒挂的名字改成单调阶梯（色值一字不动）。

## 关键决策

1. **侧栏 token 族**（`:root` 写值，`@theme inline` 只做 `var()` 映射）：`--色-侧栏-底` #304156、`--色-侧栏-子菜单` #1f2d3d、`--色-侧栏-文字` #bfcbd9、`--色-侧栏-当前` = `var(--色-主色)`（#409EFF，不另写一份十六进制）、`--色-侧栏-悬停` rgba(0,0,0,.06)、`--阴影-侧栏` 2px 0 6px rgba(0,21,41,.35)。
2. **消费面**：`admin/layout.tsx` 侧栏容器、`admin-nav.tsx` 链接 / 分组 / 子菜单底、`admin-account-area.tsx` 分区线与账户文字。学生端演练场零引用。侧栏去掉 `.卡片`（白底浅边会盖住深色），保留 4px 圆角与原有宽高、粘性、窄屏三段布局。
3. **当前项**：删掉左侧竖条；选中只改文字为主色，背景保持透明。悬停用 `--色-侧栏-悬停`。窄屏仍是 `rounded-full` 横滑胶囊。
4. **子菜单底**：仅 `lg` 下域包子项容器铺 `--色-侧栏-子菜单`。窄屏横滑条保持一整条侧栏底，避免子菜单色块把胶囊行切碎。
5. **边框阶改名**（深 → 浅）：`--色-边框-基` → `--色-边框-一阶` #dcdfe6；`--色-边框-浅` → `--色-边框-二阶` #e4e7ed；`--色-边框` → `--色-边框-三阶` #ebeef5；`--色-边框-极浅` → `--色-边框-四阶` #f2f6fc。`globals.css` 内引用全部跟过去。二阶改名前就没有直接消费者，改名后仍只作色板阶梯留位。
