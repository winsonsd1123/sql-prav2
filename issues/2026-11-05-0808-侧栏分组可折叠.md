# 侧栏分组可折叠（若依式子菜单）

## 上下文

用户以若依 RuoYi-Vue 侧栏截图为参照，指出后台侧栏两处不符：
1. 「域包管理」子菜单无法折叠（现为 spec #64 口径「子项常显」，分组标题是不可点 span）；
2. 分组标题字号（text-xs 12px 大写小节样式、无图标）与直达项（lg:text-sm 14px、带图标）不一致。

约束：尽量用项目标准控件（ADR-0011：新控件取自 shadcn）；窄屏横滑胶囊条与 rail 图标栏形态零波及（ADR-0012）。

用户决策：shadcn Collapsible；子项保留图标；账户区不动；展开状态 localStorage 持久化，当前页所在分组自动展开。

## 计划

1. `shadcn add collapsible` → `src/components/ui/collapsible.tsx`。
2. `admin-nav-routes.ts` 新增分组元数据 `ADMIN_NAV_PACK_GROUP`（label + icon 单一数据源）。
3. 新建 `admin-nav-group-store.ts`：复用 `createLocalStorage`，键 `admin.nav.group.packs`，缺省展开。
4. `admin-nav.tsx`：直达项 / 分组触发器 / 子项共用行样式；`Collapsible` + `CollapsibleContent forceMount`，仅宽屏展开态 `data-state=closed` 隐藏；窄屏触发器不可点、子项恒显；rail 态触发器隐藏、子项恒直达；进入组内页自动展开；展开组左侧主色竖线。
5. e2e：structure（可折叠 / 持久化 / 自动展开）、presentation（字号与直达项一致）、sidebar-collapse（收起分组后 rail 子项仍可见）。
6. 文档：GLOSSARY「域包组」、ADR-0012 Consequences。
7. 验证：lint / tsc / check:naming / vitest / e2e 回归；截图入 `docs/screenshots/admin-nav-collapsible/`。

## 执行记录

- `ui/collapsible.tsx` 由 `shadcn add collapsible` 生成（纯 radix 封装，零新增依赖），未改动。
- 分组图标取 `Boxes`（`Package` 已被「域包列表」占用）。
- 共用行样式 `LG_ROW_CLASS` 不含 `lg:flex`：避免与 rail 态 `lg:hidden` 同档冲突（三处元素基础类已是 `flex`）。
- 自动展开仅随路由触发（effect 依赖 pathname，不依赖 open），组内页仍可手动收起；故「刷新保持收起」用例以组外页（用户管理）为起点。
- 验证：tsc / lint / check:naming 通过；vitest 1417 通过；e2e 全量 147 通过（E2E_PORT=3321 独立构建）。
- 截图：`docs/screenshots/admin-nav-collapsible/before/expanded-1280.png`（沿用 #105 after 图）与 `after/` 三张（展开 / 分组收起 / rail）。

### 评审修复

- Spec (a) 窄屏键盘可切换：`pointer-events-none` 只挡鼠标，Tab+Enter 仍可静默写 localStorage、读屏播报虚假展开态。改为触发器 `hidden lg:flex`（rail 态 `hidden`），窄屏 `display:none` 退出 Tab 序列；另渲染 `lg:hidden` 纯文字分隔（无 testid，避免与触发器同 testid 触发严格模式）。`admin-console.spec` 窄屏用例改按可见文字定位，并补「无可见折叠按钮、五子项恒显」断言。
- Spec (c) 2px 位移：竖线 `border-l-2` 在 Collapsible 根上，触发器位于根内，展开/收起整体跳 2px（评审原判断「仅组内容位移」不准确）。改为 `shadow-[inset_2px_0_0_var(--color-sidebar-active)]` 不占布局；presentation 用例容差 2 → 1，并断言展开/收起触发器 x 不变。
- Standards #1：子项标签提到 `e2e/helpers.ts` 的 `PACK_GROUP_LINK_LABELS`（字面值作 oracle，不从 src 路由表导入，避免测试与实现同源自证）。
- Standards #3：`admin-nav-group-store.ts` 抽 `DEFAULT_OPEN`；服务端快照仍单独传（水合一致性）。`fontSize` 单次求值。
- Standards #2：登记后续 [#111](https://github.com/winsonsd1123/sql-prav2/issues/111)（侧栏手写 storage 带跨标签页同步，直接迁 `createLocalStorage` 会丢失）。Standards #4 不改。
- 已知 flake：`admin-sidebar-collapse.spec` 两条 rail 态 tooltip 用例偶发失败；基点 d2f1891 `--repeat-each=10` 4/70 同败证实为预存抖动，已登记 `docs/e2e-conventions.md`。
- 验证：tsc / lint / check:naming 通过；vitest 1417 通过；e2e 全量 146 通过 + 1 条为上述登记 flake。
