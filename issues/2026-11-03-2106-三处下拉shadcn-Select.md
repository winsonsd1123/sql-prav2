# 三处原生 select → shadcn Select（#97）

日期：2026-11-03 · 票：#97（父 spec #90，ADR 0011）· 分支：feature/ruoyi-ui-97（基点 2a34290 = main，#96 merge）· 施工方：Cursor

## 上下文

ADR 0011 一期「功能收益控件」的第三项：三处原生 select 下拉观感与若依风格不统一、面板不可定制。本票只换控件，选项集合、受控值与提交载荷不变。

`rg "<select" src` 定位到正好三处，**没有第四处**：

- `admin-domain-pack-refiner.tsx`（微调目标域包）
- `admin-domain-pack-version-history.tsx`（版本历史目标域包）
- `admin-practice-config-manager.tsx`（演练配置域包选择）

## 选型

`pnpm exec shadcn add select` 取得 `src/components/ui/select.tsx`（基于 radix-ui，依赖已有，package.json / lockfile 零变更）。

对 CLI 产物的唯一改动：选项高亮 `focus:bg-accent` → `focus:bg-[var(--accent)]`。项目中 `bg-accent` 表示「强调 = 主色 #409EFF」，与 shadcn 约定的浅底不同；按 `globals.css` 第 93-95 行注释写明的改写约束处理后，高亮为 `--色-行悬停` #f5f7fa，与若依 Element 下拉悬停一致。未改写时实测悬停为主色实底配深色字，对比度不足。

## 改动

1. **新增 `src/components/pack-base-select.tsx`**：微调与版本历史两处结构相同（「请选择域包」占位项 + `名称（基础名）` 选项），收为一个共享组件 `PackBaseSelect`。Radix 不允许选项值为空串，因此占位项用哨兵值 `__placeholder__` 承载，进出组件时与 `""` 互转：
   - 受控值 `""` 显示「请选择域包」（等价于原生 `value=""`）
   - 占位项仍能被选回，回调收到 `""`（等价于原生选回 `<option value="">`；微调页注释里「含选回占位项」的语义保持）
2. **微调页**：`value={selectedBase}`、`onValueChange={setUserSelected}`、`disabled={busy}` 一一对应原 `value` / `onChange` / `disabled`。预选派生逻辑（清单异步就绪后预选生效）不动。触发器 `w-full` 保持原先在 flex-col label 内撑满的宽度
3. **版本历史页**：`onValueChange` 内依次执行 `setSelectedBase` / `setVersions(null)` / `setError(null)`，与原 `onChange` 逐行相同
4. **演练配置页**：直接用 `ui/select`（没有占位项，不需要哨兵）。`id="practice-config-pack"` 挂到触发器上，`<label htmlFor>` 关联保持；`onValueChange={switchPack}`。`FEEDBACK_TOAST` / `FEEDBACK_ERROR_TOAST` 常量、`switchPack` 里的 `toast.dismiss`、`save` 一字未动（diff 只涉及 import 与下拉 JSX）
5. **面板**：三处都用 `position="popper" align="start"`，面板在触发器正下方、左对齐（Element 下拉形态）。Radix 默认的 `item-aligned` 会把面板盖在触发器上，`align` 默认居中会让面板相对触发器左偏
6. **键盘**：Radix Select 自带 Enter / Space / 方向键展开，方向键移动高亮，Enter 确认，Esc 关闭，关闭后焦点回到触发器，并支持按字母快速定位

## testid 与 e2e

三个 testid 原样挂在 `SelectTrigger` 上。触发器是 button，没有原生 value，`toHaveValue` / `selectOption` 不再适用，按「断言语义不变、写法换等价形式」改写：

| 原写法 | 现写法 | 语义 |
|---|---|---|
| `toHaveValue("<基础名>")` | `toContainText("（<基础名>）")` | 选中的是该基础名（选项文案为「名称（基础名）」，全角括号定界，不会误匹配） |
| `toHaveValue("")` | `toHaveText("请选择域包")` | 停在占位项 |
| `selectOption("<基础名>")` | `chooseSelectOption(page, testId, "（<基础名>）")` | 选中该项（helpers.ts 新增：点开触发器 + 按 role=option 点选） |

涉及 `domain-pack-refine` 9 处（其中 1 处为版本历史 testid）、`domain-pack-versions` 3 处、`domain-pack-list-page` 2 处、`admin-nav-structure` 1 处；`admin-nav-structure` 两处 `toBeVisible` 与 `domain-pack-list-page` 一处 `toHaveCount(0)` 未改动，照常通过。

新增 e2e 2 例：

- `domain-pack-versions.spec.ts`「下拉键盘可达（#97）」：聚焦触发器后 Enter 展开 listbox → ArrowDown 高亮离开占位项 → Enter 确认 → listbox 关闭、触发器显示所选项、焦点回到触发器、版本表查询出结果
- `practice-config.spec.ts`「域包下拉切换（#97）」：切到第二个包后草稿回填为该包配置（总题数 10、档4 模板数 6），之前未保存的编辑被丢弃；保存后 PUT 载荷 `packId` 为所选包、配置为编辑值；刷新后选中项保持

两例各 `--repeat-each=10 --workers=6` 压测，全过。

## 发现待办（范围外，未修）

1. **e2e 网络抖动的实际根因**：全量跑出现的 `ERR_CONNECTION_CLOSED`，trace 定位为学生端演练场对 `e2e-placeholder.supabase.co/rest/v1/practice_progress` 的**未打桩真实请求**（打向不存在的占位主机，失败形态随本机网络变化）。本票各轮命中 `cloud-domain-pack.spec.ts:35/53` 与 `admin-console.spec.ts:217`（登记表记作 `:214`，行号已漂移）。三条均已在 `docs/e2e-conventions.md` 登记；单跑通过；本票改动不经过学生端演练场。基点 2a34290 隔离 worktree 全量连跑 2 轮都是 129 全过，这次没能复现，符合随机抖动的特征。建议在 #98 console 卫生收口时给这几条 spec 补 `createCloudProgressStub`，从根上消除，而不只是登记
2. **演练配置切包时多一次重拉**：`refresh` 的 `useCallback` 依赖 `selectedPackId`，`useEffect([refresh])` 会在每次切包后再 GET 一次，并用服务端配置重置草稿。切包后若在这次 GET 返回前开始输入，输入会被覆盖。这是存量行为，原生 select 下同样存在（新增用例全量负载下踩到过，已改为等这次重拉返回后再填）。修复方向：首拉与切包解耦，例如 effect 只在挂载时执行，或让 refresh 通过 ref 读取选中值
