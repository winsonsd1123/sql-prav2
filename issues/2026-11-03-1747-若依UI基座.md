# 若依 UI 基座：shadcn/ui 初始化 + 若依色板与中文 token 合流（#92）

日期：2026-11-03 · 票：#92（父 spec #90，ADR 0011）· 分支：feature/ruoyi-ui-92（基点 e98ad9a = main HEAD）· 施工方：Cursor

## 上下文

组件早已全部消费语义 token（Tailwind 工具类 `text-muted`/`bg-panel`/`border-ink` 等 + `globals.css` 中文控件类），本票只换 token 值与主题基座，不逐个改组件，全站即换为若依浅色观感。

## 关键决策

1. **单一事实源 = 中文 token**：`:root` 中只有中文 token（`--色-*`）写十六进制色值；shadcn 主题变量（`--background`/`--primary`/`--border`/`--ring` 等）一律 `var(--色-*)` 映射，不写任何色值。shadcn init 生成的 oklch 值、`chart-*`、`sidebar-*` 变量全部删除（admin 深色侧栏族归后续票，用到时再加）。
2. **既有 token 名保留、值换若依**：`--色-墨`=#303133、`--色-次文`=#606266、`--色-面板`=#fff、`--色-边框`=#EBEEF5、语义四色等；新增 `--色-主色/主悬停/主按下/主禁用`、`--色-辅文/占位`、边框阶 `--色-边框-基/浅/极浅`、`--色-表头底/表头字/行悬停`、`--色-中性`、`--阴影-卡片`。派生关系用 `var()` 引用（`--色-底`→边框极浅 #F2F6FC、`--色-深`→行悬停 #F5F7FA、`--色-强调`→主色、`--色-反色`→面板）。
3. **工具类名冲突**：shadcn 约定的 `muted`/`accent` 是浅底色，而项目既有 `text-muted`（151 处，次文色）与 `accent`（强调）已占名。为「不改组件」保留项目语义，shadcn 原始变量 `--muted`/`--accent` 照常定义，`muted-foreground`/`accent-foreground` 不受影响；`globals.css` 内注释写明取用 shadcn 组件时的改写约束。
4. **暗色**：删除 `prefers-color-scheme` 分支与 shadcn 生成的 `.dark {}` 块；保留 `@custom-variant dark (&:is(.dark *))`——否则 Tailwind v4 的 `dark:` 默认走系统偏好，shadcn 组件自带的 `dark:` 类会把暗色带回来。全站从不挂 `.dark`，`dark:` 永不生效。
5. **表格表头/行悬停**：在 `@layer base` 写 `thead th`（#f8f8f9 / #515a6e）与 `tbody tr:hover`（#F5F7FA），组件零改动即生效；处于 base 层，组件显式工具类仍可覆盖。
6. **圆角**：`--radius: 4px`，`.卡片`/`.主按钮`/`.次按钮`/`.输入框` 统一 `var(--radius)`；shadcn 的 `radius-sm…4xl` 随之按比例缩放，组件里的 `rounded-lg/xl/2xl` 一并收紧到若依尺度。
7. **控件类换值**：`.主按钮` 改 Element 主按钮（蓝底白字，hover/active/disabled 三态）；`.次按钮` 改 Element 默认按钮（白底 #DCDFE6 边，悬停主色浅底 #ecf5ff / 浅边 #b3d8ff / 蓝字）；`.输入框` 改白底灰边、聚焦主色边、占位 #C0C4CC。类本身不废除（二期的活）。
8. **点阵画布删除**：`--网格色` 与 body 点阵背景属「静室」视觉特征，随代号一并废弃。
9. **shadcn init 回滚项**：init（radix 基座、nova 预设）自动给 `layout.tsx` 挂了 Geist 字体并把 `--font-sans` 改指 Geist——违反「字体挂载不动」，`layout.tsx` 整体还原、`--font-sans` 恢复 Noto Sans SC 字体栈。
