# 硬编码色收编：原生色类 → 语义 token + CodeMirror 容器底色直连 + 侧栏分界别名（#94）

日期：2026-11-03 · 票：#94（父 spec #90，ADR 0011）· 分支：feature/ruoyi-ui-94（基点 1082fe4 = main，#93 merge）· 施工方：Cursor

## 上下文

#92 立了中文 token 唯一色值源，#93 加了侧栏族与边框阶。本票把组件里绕开 token 的色值收干净，并按 #93 验收拍板拆开 `--色-侧栏-子菜单` 的双职。票面写「4 处」，交接约定「以全库扫描为准」，实扫出 11 个 admin 文件的 Tailwind 原生色类与编辑器的兜底色值写法，全部收编。

## 扫描方法

```
rg -n '#[0-9a-fA-F]{3,8}\b|rgba?\(|hsla?\(|oklch\(|\b(amber|red|green|blue|yellow|gray|slate|zinc|neutral|stone|orange|emerald|teal|sky|indigo|violet|purple|pink|rose|lime|cyan|fuchsia)-\d{2,3}\b|\b(text|bg|border|ring)-(white|black)\b|var\(--[^)]*,|\[#|\[rgb' src
```

- 改前：`globals.css` 之外命中 SqlEditor 4 处（`var(--色-面板, #fff)` / `var(--色-墨, #111)` 兜底）+ 11 个 admin 文件的 red / emerald / amber / sky / `text-white` 原生类
- 改后：`globals.css` 之外 **0 命中**；`globals.css` 内的色值全部是 `:root` token 定义（唯一色值源，预期内）
- 登录/注册/重置等表单的 `style={{ color: "var(--色-错误)" }}` 已走 token、无色值，不在收编范围

## 关键决策（按语境映射，不机械对照）

1. **状态反馈**：错误 `red-50/700` → `bg-fail/10 text-fail`；成功/已放出/当前版本/启用中 `emerald-50/700` → `bg-pass/10 text-pass`；警示类 `amber-50/700/800` → `bg-warn/10 text-warn`（未配置提醒、草稿不完整、校验提示、「被 N 个域包引用」、diff B 类与「修改」动作）
2. **选中态归主色**：详情页 / 模板选择的选中卡 `border-emerald-600 ring-emerald-600` → `border-primary ring-primary`；「已选」实心徽章 `bg-emerald-700 text-white` → `bg-primary text-primary-foreground`（`--色-主字`）；知识点选中行 → `bg-primary/10 ring-primary`；微调页「元素微调目标」横幅同属选中语境 → `border-primary/40 bg-primary/10`。原绿色选中与「通过」语义冲突，按 Element 惯例改主色
3. **骨架列标注**：「主键」`emerald-700` → `text-accent`（与演练场表结构 PK 徽章同为主色）；外键「引用 表.列」`amber-700` → `text-neutral`（说明性标注、非警示，取 `--色-中性` #909399）。为此在 `@theme inline` 补桥接 `--color-neutral: var(--色-中性)`（token 早已存在，之前无消费者）
4. **链接**：`sky-700` → `text-accent`
5. **编辑器容器**：去掉 `var(..., #fff)` / `var(..., #111)` 兜底写法，直连 `--色-面板` / `--色-墨`；扩展结构、字体、受控同步不动；过时注释「随亮暗主题切换」改为当前事实
6. **侧栏分界别名**：新增 `--色-侧栏-分界: var(--色-侧栏-子菜单)` 与桥接 `--color-sidebar-divider`；分界线两个消费点（`admin/layout.tsx` 导航区上边线、`admin-account-area.tsx` 账户区上边线）改引 `border-sidebar-divider`；`bg-sidebar-sub` 只剩宽屏子菜单分组底一个消费点。别名用 `var()` 引用，色值仍唯一
