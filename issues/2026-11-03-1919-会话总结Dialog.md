# 会话总结手写弹层 → shadcn Dialog（#95）

日期：2026-11-03 · 票：#95（父 spec #90，ADR 0011）· 分支：feature/ruoyi-ui-95（基点 b3602c6 = main，#94 merge）· 施工方：Cursor

## 上下文

ADR 0011 点名的真实缺陷之一：`SessionSummary` 是 `fixed` 居中的手写 `section`，无焦点陷阱、无 Esc、无 Portal、背景可滚动穿透。本票换成 shadcn 官方 Dialog，内容与触发语义不动。

## 改动

1. **CLI 取组件**：`pnpm exec shadcn add dialog` 产出 `src/components/ui/dialog.tsx` 与其依赖 `src/components/ui/button.tsx`（Dialog 自带关闭按钮引用）。`radix-ui` 统一包 #92 已入依赖，故 `package.json` / lockfile **零变更**；组件文件原样保留 CLI 产物
2. **`SessionSummary.tsx`**：改为受控 `Dialog open`，`onOpenChange(false)`（Esc / 点遮罩）→ `onClose`；`data-testid="会话总结卡"` 挂在 `DialogContent` 上；「会话完成」→ `DialogTitle`（自动成为 `aria-labelledby`）、「总通过 x/y」→ `DialogDescription`（满足 Radix 无障碍要求，避免 console 警告）；三档图例、两枚按钮、全部 testid 与文案逐字不变；`showCloseButton={false}`——不加票面没有的关闭 X（关闭路径已有「回顾题目」与 Esc）
3. **关闭还焦点**：Radix 在无 `DialogTrigger` 时把焦点还给空的 trigger ref（落到 body）。又因验证按钮判题期间 `disabled` 已失焦，「打开前的焦点」也是 body，记录 activeElement 方案实测失败。故由 `Playground` 把验证按钮 ref 作为 `returnFocusRef` 传入，`onCloseAutoFocus` 中 `preventDefault` 后聚焦之
4. **`Playground.tsx`**：渲染条件由 `summaryOpen && session` 改为 `session &&` + `open={summaryOpen}`（让 Dialog 自管开合动画）；触发语义（`wasAllPassed` 事件性弹出、刷新不重弹）未动
5. **`globals.css`**：删除只服务于手写弹层的 `.居中浮现` 与 `@keyframes 浮现`（全库无其他消费者）；按钮仍用 `.主按钮` / `.次按钮`（按钮迁移属二期，Out of Scope）
6. **e2e**：`playground-smoke.spec.ts` 「会话总结与完成分档」节新增 2 例，照抄 `seedMixedProgress` 触发——Esc 关闭且焦点回到验证按钮；Tab×3 / Shift+Tab×3 每步断言焦点仍在弹窗内

## Acceptance criteria

- [x] 会话总结弹窗为 shadcn Dialog（Portal 渲染），打开时背景不可滚动穿透——探针：弹窗父节点为 `BODY`（Portal）、`role="dialog"`、`aria-labelledby` 指向「会话完成」；`body` 计算样式 `overflow: hidden` 且带 `data-scroll-locked`
- [x] Esc 可关闭；焦点陷阱生效：Tab 循环不离开弹窗，关闭后焦点回到触发元素——新增 e2e 两例覆盖

- [x] 新增 e2e 用例：Esc 关闭与焦点被困两个可观察行为
- [x] Vitest 全绿、e2e 全量回归绿
