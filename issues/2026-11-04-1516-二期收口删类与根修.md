# 二期收口：删中文控件类定义 + ui/input + 三根修（#102）

日期：2026-11-04 · 票：#102（父 spec #91）· 分支：feature/102-final-contract（基点 ee78969 = main）· 施工方：Cursor

## 上下文

expand–contract 的 contract 阶段：删 `globals.css` 中文控件类定义（`.卡片`/`.主按钮`/`.次按钮`/`.输入框` 四族），新建 `ui/input.tsx` 并迁移全库 13 处输入框（含 `.错误` 态、死类 `次输入框`），落 #99/#100/#101 验收沉淀的三个组件级根修（ghost hover、Button 禁用态、Table 容器 className），全量回归并产出与若依 demo 的并排素材。红线：`--色-*` token 不动、testid 不动、删类后观感不变、效果类不迁不删。

## 盘点核对（与交接文档的出入）

1. **控件类并未清零：`email-verification-callback.tsx` 残留 `.卡片` ×2 + `.主按钮` ×1**（#99 漏迁）。按交接红线 1「有残留先迁后删」迁移：卡片 → `Card`，`.主按钮` Link → `Button asChild size="lg" className="mt-5 px-4"`（照搬 #99 `reset-password-form` 同形态先例）
2. **`not-disabled:hover:*` 有优先级陷阱**：编译产物 `.x:not(:disabled):hover` 为 (0,3,0)，使用点裸 `hover:*` 为 (0,2,0)，`cn` 视两者为不同修饰符都保留 → 变体悬停色必胜。会打掉 3 处使用点覆盖：词表「删除」`hover:text-fail`（#100 补丁，#101 评论要求勿回退）、`Playground.tsx` 题目列表 `hover:bg-ink/[0.06]`/`[0.04]`
3. **白名单两个输入框的 `text-xs` 从未生效**：`.输入框` 为 unlayered 样式，压过 utilities 层，实际 14px；迁 `Input` 后 `cn` 会让 12px 突然生效
4. **Dialog 关闭按钮全站无渲染点**：唯一的 `SessionSummary` 设了 `showCloseButton={false}`，ghost 根修对它的「自动受益」是潜在的，当前无可见变化
5. 输入框 13 处分布与文档一致：认证四页 6 处（register 为循环 1 处）、词表 4、白名单 2、用户搜索 1

## 施工前拍板（用户 2026-11-04）

1. **优先级陷阱**：变体按文档改 `not-disabled:hover:*`，3 处使用点覆盖同步改成 `not-disabled:hover:*`（`cn` 同修饰符正确去重，实测见「验证」）；约定写进 `button.tsx` 注释
2. **白名单 `text-xs`**：删掉，保持 14px 观感不变

## 改动

### ① 删控件类定义（`globals.css`）

删 `.卡片`、`.主按钮`（+hover/active/disabled）、`.次按钮`（+hover/disabled）、`.输入框`（+placeholder/focus/disabled/`.错误`）。保留 `.标题`、`.入场/-2/-3`、`.落章`、`.呼吸`、`.横滑` 与三个 keyframes。删前检索：`className`/`cn()`/模板串/CSS 选择器四种形态，控件类引用为零（其余 `错误` 命中均为判题结果值）。

`--色-*` token 35 个与 main 逐行 diff 一致。注：`--色-主悬停`/`--色-主按下`/`--色-主禁用` 原只被 `.主按钮` 消费，删类后无引用，按红线保留（三期可议）。

### ② `ui/input.tsx` + 13 处迁移

shadcn v4 形态（`data-slot="input"`、`cn` 合并），值逐项对照 `.输入框`：

| `.输入框` | Input |
|---|---|
| 白底 / 次文字 / 一阶边框 / `--radius` | `bg-card text-muted border border-input rounded-lg`（`text-muted` 本项目 = 次文） |
| `0.875rem/1.25rem`、`py-2 px-3`、`width:100%` | `text-sm py-2 px-3 w-full` |
| `transition: border-color 150ms` | `transition-[border-color]` |
| `::placeholder` 占位色 | `placeholder:text-[var(--色-占位)]` |
| `:focus` 无 outline + 主色边 | `outline-none focus:border-ring`（**不加** shadcn 默认 ring 光晕，保观感） |
| `:disabled` 深底 + 占位字 + not-allowed | `disabled:bg-secondary disabled:text-[var(--色-占位)] disabled:cursor-not-allowed` |
| `.错误` 错误色边 | `aria-invalid:border-destructive`（实测 Tailwind 输出顺序 aria-invalid 在 focus 之后，聚焦时仍保红边，同原 `.输入框.错误` 后置语义） |

未带 shadcn 默认的 `min-w-0`：原类无此属性，带上会改变用户搜索框在 flex 行内的收缩行为。

使用点：认证四页 `className="输入框"` 删除；`.错误` 三处改 `aria-invalid={cond ? true : undefined}`（条件表达式逐字照搬：`errors[key]` / `emailError` / `error`）。白名单删 `text-xs`（拍板 2），保留 `min-w-0 flex-1 basis-* font-mono`。词表 4 处删死类 `次输入框`，原内距保留（新增 `py-1.5`、编辑 `px-2 py-1`），`rounded-lg text-sm` 与 Input 同值删去。testid / `type` / `autoComplete` / `aria-label` / `disabled` 原样。

### ③ 三个根修

1. **ghost hover**：`hover:bg-muted` → `bg-secondary`（行悬停浅灰），`aria-expanded` 同改（拍板 3）。删反覆盖 3 处：Playground 域包胶囊选中态 `hover:bg-panel hover:text-ink`、未选态 `hover:bg-transparent hover:text-ink`，生成页「放弃本次草稿」`hover:bg-transparent hover:text-ink`（`hover:text-ink` 与 ghost 自带 `text-foreground` 同色，一并删）
2. **Button 禁用态**：基类 `disabled:pointer-events-none` → `disabled:cursor-not-allowed`；6 个变体悬停全改 `not-disabled:hover:*`。用户页 `LOCK_HOVER_HINT`/`LOCK_HOVER_RESET` 常量及两处挂载删除（`variant` 中间变量随之内联）。使用点覆盖改前缀：词表删除 `not-disabled:hover:text-fail`、Playground 题目列表两态 `not-disabled:hover:*`（拍板 1）。`active:translate-y-px` 未加守卫——实测禁用按钮按下 `transform: none`（Chromium 不对 disabled 匹配 `:active`）
3. **`ui/table.tsx` 容器 className**：`Table` 新增 `containerClassName` 透传给 `table-container`。用户页删外层任意变体包裹 div，改 `containerClassName="横滑"`；8 处 `whitespace-normal` 收拢为 `Table` 上一处 `[&_td]:whitespace-normal`（8 处恰为全部 td，表头 th 保持 nowrap，等价）
