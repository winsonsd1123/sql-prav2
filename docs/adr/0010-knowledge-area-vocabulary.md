# 知识点：全局词表 + 域包有序引用清单

0008 把知识点清单（knowledgeAreas）定为域包私有字段后，跨包各自为政：教师既无法维护一套可扩充的公共知识点，也无法在生成/微调时限定取值范围，LLM 起草各包时知识点名自由发挥、跨包漂移不可控。现引入全局「知识点词表」作为知识点的唯一来源：条目含名称与描述，可启停，被域包引用的条目不可删除；域包持有从词表圈选的**有序引用清单**（词表的有序子集），抽题按包内清单顺序分区推进的既有语义不变（0009 的 B 类分界同样不变）。域包生成时圈选是可选步骤：圈选即封闭——所产清单只能取自圈选集合；未圈选则维持现状（清单自由产出，新条目不入词表），向后兼容。

## Considered Options

- **完全全局化（域包直接使用全局清单，去掉包内清单）**：丢掉「各包自带子集与顺序」的领域语义，抽题按包内清单顺序分区推进的行为随之破坏，波及抽题内核，被否决。
- **维持域包私有（不建全局词表）**：「扩充公共知识点」与「限定生成/微调取值范围」两个诉求都无从满足，被否决。
- **开放词表（LLM 造新词发布时自动入库）**：词表随每次生成无限膨胀，「限定」失效，与封闭式受控词表的初衷相悖，被否决。

## Consequences

- 词表管理页提供 CRUD 与启停；被引用条目禁物理删除（防悬挂引用），停用条目仍可被既有包引用、只是不能再被新圈选。
- 域包资产中的知识点清单从纯字符串数组演进为对词表条目的有序引用；历史版本资产的旧形态需兼容读取。
- 内置两包的既有清单合并去重后作为词表初始数据；`question-picking.ts` 的七类回退常量在词表落地后失去存在理由，可一并移除。
- GLOSSARY 的「知识点」条目改写、新增「知识点词表」条目；「域包微调」补元素级锚定语义。
