# Triage 标签

各 skill 以五个规范的 triage 角色表述。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我方跟踪器中的标签 | 含义                             |
| -------------------------- | ------------------ | -------------------------------- |
| `needs-triage`             | `needs-triage`     | 维护者需要评估此 issue           |
| `needs-info`               | `needs-info`       | 等待报告者提供更多信息           |
| `ready-for-agent`          | `ready-for-agent`  | 已完全明确，可供 AFK agent 执行  |
| `ready-for-human`          | `ready-for-human`  | 需要人工实现                     |
| `wontfix`                  | `wontfix`          | 不予处理                         |

当 skill 提到某个角色（如"应用 AFK-ready triage 标签"）时，使用本表中对应的标签字符串。

编辑"我方跟踪器中的标签"列即可匹配你实际使用的词汇表。
